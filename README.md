# Quantitative Methods with Python

## Project Overview

This project demonstrates the application of Python programming to mathematical analysis, numerical methods, and linear algebra as part of my Quantitative Methods I coursework at Hochschule Coburg.

The project helped me develop practical skills in mathematical problem-solving, numerical computation, data visualization, and Python programming.

## Project Contents

### 1. Mathematical Analysis
File: `analysis_akarsh_ashok.ipynb`

Topics covered:
- Mathematical functions and visualizations
- First and second derivatives
- Numerical differentiation using central differences
- Tangent lines
- Newton-Raphson root-finding method
- Taylor polynomial approximation
- Numerical integration using the trapezoidal rule

### 2. Linear Algebra
File: `linearalgebra_akarsh_ashok.ipynb`

Topics covered:
- Matrix creation and operations
- Column normalization
- Transition matrices
- Matrix powers and convergence
- Eigenvalues and eigenvectors
- Stationary distributions

## Technologies and Libraries

- Python
- NumPy
- Matplotlib
- SymPy
- Google Colab / Jupyter Notebook

## Key Learning Outcomes

- Applied mathematical concepts using Python.
- Compared analytical and numerical solutions.
- Used numerical methods to approximate roots and integrals.
- Explored matrix transformations and stationary distributions.
- Improved Python programming and problem-solving skills.

## How to Run

1. Open either `.ipynb` notebook.
2. Select **Open in Colab** or download it and open it in Jupyter Notebook.
3. Run the cells from top to bottom.
